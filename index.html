Minecraft setup for Hazel

Hazel needs her own Microsoft account. Redeem the Java + Bedrock key on her login. You’ll play Java together on PCs — not PlayStation.

1 Your Microsoft account 2 Create her child account 3 Allow code redemption 4 Buy the ~$20 key 5 Redeem on her account 6 Install Java — basic or fancy 7 Play together (Aternos) 8 Optional fancy graphics

01 Your Microsoft account

Go to account.microsoft.com and sign in (or create one).

02 Create her child account

  1. Go to account.microsoft.com/family
  2. Click Add a family member → Child
  3. Use her email, or create one for her
  4. Use her real birth year
  5. Accept the invite so she shows under Family members

03 Allow her to redeem codes

Child accounts often block this until a parent turns it on.

  1. Still in Family, open her profile
  2. Allow content suitable for age 10+
  3. Allow her to redeem codes / spend if that toggle is there

04 Buy the game (~$20)

Official Microsoft Store price is $29.99. This Eneba listing is the Java + Bedrock for PC bundle. You need Java; Bedrock comes along for free on the same key.

Buy the official website key on Eneba
  • Buy a key, not an “account”
  • Confirm the offer activates in the United States
  • Pick a high-rated seller

There is also a Windows Store key. Same game — it just redeems in the Microsoft Store instead of minecraft.net.

05 Redeem on her account

  1. Sign in as her at minecraft.net/redeem
  2. Paste the 25-character code
  3. Confirm

If you bought the Windows Store version: Microsoft Store → profile icon → Redeem code, still signed in as her.

06 Install Java — pick one

Pick one column. Fancy replaces Basic — do not install both launchers. Write down her Minecraft username (often her Xbox gamertag), not her email.

Basic

Official launcher. Normal Minecraft look. Easiest.

  1. Install the Minecraft Launcher
  2. Sign in as her
  3. Play Java Edition (not “Minecraft for Windows”)
  4. Launch once

Fancy

Prism is a free extra launcher. It can load a prebuilt pack with shaders. Same game, prettier.

  1. Install Prism Launcher (Windows installer)
  2. Sign in as her
  3. Add Instance → Import from zip (this also takes a .mrpack)
  4. Select the weisspack file from step 8 — do not unzip it
  5. Launch that instance once

07 Play together (Aternos)

Everyone who joins must be on a computer, in Java Edition. A PlayStation / Xbox / phone copy cannot join.

The world is on a free Aternos server. Someone with access to that Aternos page hits Start and waits a minute before anyone can join.

  1. Use vanilla Java, same version as the server
  2. Send her Minecraft username so she can be added to the whitelist
  3. In Java: Multiplayer → Add Server → rymiwe.aternos.me

Same house also works with Open to LAN, no server needed.
