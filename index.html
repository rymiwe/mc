Windows PC · Java Edition

Minecraft setup for Hazel

Hazel needs her own Microsoft account. Redeem the Java + Bedrock key on her login. You’ll play Java together on PCs — not PlayStation.

1 Your Microsoft account 2 Create her child account 3 Allow code redemption 4 Buy the ~$20 key 5 Redeem on her account 6 Install Java — basic or fancy 7 Play together (Aternos) 7b Start the server

01 Your Microsoft account

Go to account.microsoft.com and sign in (or create one).

02 Create her child account

  1. Go to account.microsoft.com/family
  2. Click Add a family member → Child
  3. Use her email, or create one for her
  4. Use her real birth year
  5. Accept the invite so she shows under Family members

03 Allow her to redeem codes

Child accounts often block this until a parent turns it on.

  1. Still in Family, open her profile
  2. Allow content suitable for age 10+
  3. Allow her to redeem codes / spend if that toggle is there

04 Buy the game (~$20)

Official Microsoft Store price is $29.99. This Eneba listing is the Java + Bedrock for PC bundle.

Buy the official website key on Eneba
  • Buy a key, not an “account”
  • Confirm the offer activates in the United States
  • Pick a high-rated seller

05 Redeem on her account

  1. Sign in as her at minecraft.net/redeem
  2. Paste the 25-character code
  3. Confirm

06 Install Java — pick one

Pick one column. Fancy replaces Basic — do not install both. Write down her Minecraft username.

Ryan will tell you which column to use. Default: Basic.

Basic

Official launcher. Normal look. Works with the current Aternos server.

  1. Install the Minecraft Launcher
  2. Sign in as her
  3. Play Java Edition (not “Minecraft for Windows”)
  4. Launch once

Fancy

Prism is a free extra launcher. Same game, shaders. Only if Ryan says the server matches.

  1. Install Prism Launcher
  2. Sign in as her
  3. Download weisspack below — do not unzip it
  4. Add Instance → Import from zip → pick the .mrpack
  5. Launch that instance once
Download weisspack

07 Play together (Aternos)

Everyone must be on a computer, in Java Edition.

The world is on Aternos. Someone with access hits Start and waits a minute.

  1. Use vanilla Java, same version as the server
  2. Send her Minecraft username for the whitelist
  3. Multiplayer → Add Server → rymiwe.aternos.me

7b Start the server

Ryan already owns the Aternos server. You can start it without his password.

  1. Create your own free account at aternos.org
  2. Text Ryan that Aternos username (not Hazel’s Minecraft name)
  3. He will grant you Access → Start
  4. Open the server → Start → wait until it is online
  5. Then she joins rymiwe.aternos.me in Java
